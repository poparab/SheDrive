# Prompt: Story From Backlog Item

Turn the selected SheDrive backlog item into a full user story using the project story format.

Do not include implementation details.
Add validation tables, grid specs, scope boundaries, and UX notes only when needed.
If the output will be entered into Azure DevOps, use HTML for description and acceptance criteria fields, use `<ol>` and `<ul>` for lists, and use bordered HTML tables instead of Markdown tables.
