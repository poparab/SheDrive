# SheDrive MVP User Stories

## Purpose

This file is the curated backlog working surface for sprint-ready SheDrive stories. It should gradually replace raw backlog interpretation work with story-quality deliverables.

## Refinement Order

1. Rider onboarding and booking
2. Rider active trip and SOS
3. Driver onboarding and request handling
4. Driver active trip and earnings
5. Admin access, onboarding queue, and SOS queue
6. Finance, pricing, and reporting workflows

## Definition Of Ready

A story is ready when it has:
- a stable persona
- a clear business outcome
- 3 to 6 acceptance criteria
- validation and grid details where needed
- scope boundary notes when part of a larger workflow
- visible dependencies
