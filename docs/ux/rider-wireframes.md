# Rider Wireframes

## Purpose

This file tracks rider mockup intent before or alongside HTML implementation in `shedrive-web/rider/`.

## Screen Set

1. Splash and login
2. Identity verification
3. Home and booking
4. Matching
5. Active trip
6. SOS takeover
7. Trip completion and rating
8. History
9. Trusted contacts

## UX Rules

- mobile-first
- safety cues always visible
- minimal copy per screen
- Arabic and English parity
- every state must be mockable without backend dependency
