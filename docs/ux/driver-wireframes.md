# Driver Wireframes

## Purpose

This file tracks driver mockup intent before or alongside HTML implementation in `shedrive-web/driver/`.

## Screen Set

1. Login
2. Onboarding
3. Home
4. Incoming request
5. Active trip
6. Earnings
7. Cash balance
8. SOS takeover

## UX Rules

- mobile-first
- clear action hierarchy
- confidence and safety cues
- Arabic and English parity
- operational states must be obvious at a glance
