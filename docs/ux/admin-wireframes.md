# Admin Wireframes

## Purpose

This file tracks admin portal mockup intent before implementation under `shedrive-web/admin/`.

## MVP Screen Set

1. Login with 2FA
2. Operational dashboard
3. Driver onboarding queue
4. Rider profile
5. Driver profile
6. Live rides
7. SOS queue
8. Zone and pricing configuration
9. Reconciliation
10. Audit log
11. Reports

## UX Rules

- desktop-first
- English-only for MVP
- operational density over marketing polish
- every grid must have explicit columns and filters
