# SheDrive Wireframes

Use this skill when producing rider, driver, or admin mockup definitions for `shedrive-web/`.

## Workflow

1. Read the source story and acceptance criteria first.
2. Define the screen purpose in one sentence.
3. List:
   - visible sections
   - primary CTA
   - secondary CTA
   - loading state
   - empty state
   - error state
   - success state
   - safety-critical state if relevant
4. Keep the output mobile-first unless the work is explicitly for the admin portal.
5. Note any required i18n keys and accessibility labels.

## Guardrails

- Stay within the static HTML/CSS/ES modules stack.
- Reuse shared components and design tokens.
- Do not invent hidden backend behavior.
