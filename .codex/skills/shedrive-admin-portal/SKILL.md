# SheDrive Admin Portal

Use this skill for admin, ops, support, finance, and compliance portal work.

## Workflow

1. Identify the role first.
2. Define the goal of the screen or workflow.
3. For each grid, specify:
   - columns
   - sortable fields
   - filters
   - pagination
   - export need
4. For each action, specify:
   - permitted roles
   - confirmation need
   - audit log event
   - result state

## Guardrails

- English-only UI for MVP.
- Avoid mixing finance actions with support actions unless the workflow explicitly requires it.
