# SheDrive Prompt Hooks

These are non-script hooks for the project. They exist to reduce drift without forcing Python or other automation.

Use them as a checklist before substantial product, backlog, or mockup work.

- `pre-story-checklist.md`
- `pre-mockup-checklist.md`
- `pre-admin-checklist.md`
- `pre-finalize-ui-checklist.md`
- `pre-backlog-approval-checklist.md`
